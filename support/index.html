FAQ

EasySpend questions

Does EasySpend work offline?

Yes. EasySpend is designed to work offline by default for core expense tracking and budgeting workflows.

Is my financial data uploaded?

No. EasySpend stores financial data locally by default. Future backup features will be optional if introduced.

Can I backup my data?

Backup availability depends on the released app version. Future backup notes will be added here when available.

Does the app require an account?

No account is required for the core offline-first EasySpend experience.
